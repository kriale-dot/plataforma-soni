# GitHub — Plataforma SONI

Repositório oficial: https://github.com/kriale-dot/plataforma-soni

**Estado em 2026-10-15:** repositório criado pelo responsável, liberado para a integração ChatGPT/GitHub e inicializado. Não é necessário criar outro repositório.

## Clonar no Windows
git clone https://github.com/kriale-dot/plataforma-soni.git

## Desenvolver e publicar alterações locais
git status
git add .
git commit -m "feat: descrição da entrega"
git push origin main

A integração ChatGPT/GitHub também pode criar commits diretamente, conforme permissões atuais.

**Nunca incluir api/.env nem outros segredos.** Manter docs/SONI_CONTEXT.md, docs/SONI_STATUS.md e docs/SONI_VERSIONS.md atualizados.
