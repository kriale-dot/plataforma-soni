# Plataforma SONI

Plataforma educacional de **sonorização de igrejas**, com site institucional, testes interativos de texto, imagem e áudio, biblioteca de documentos PDF/PNG e vídeos por YouTube ou upload.

- **Frontend:** React + Vite
- **Backend:** PHP + Slim Framework 4
- **Banco de dados planejado:** MySQL 8
- **Paleta oficial:** **Harmonia Técnica (Paleta 1)**: petróleo `#153B4A`, turquesa `#2FA89C`, areia `#F3EBDD`, âmbar `#D8A24A`, grafite `#27333A`.
- **Admin:** credenciais (e-mail e hash da senha) armazenadas exclusivamente no `api/.env`, que **não** deve ser enviado ao GitHub.

**Status:** v0.1.0, estrutura e telas demonstrativas. Recursos de gestão, uploads e testes reais ainda não estão concluídos.

Consulte os documentos em `docs/` para contexto permanente, versões, requisitos e acompanhamento. Em cada etapa, atualizar `docs/SONI_STATUS.md` e `docs/SONI_VERSIONS.md`.
